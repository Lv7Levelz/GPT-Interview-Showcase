# GPT Interview

A cinematic, interactive portfolio/demo website built with plain HTML, CSS and JavaScript.

## Deploy on GitHub Pages
1. Create a new GitHub repository.
2. Upload **all files from this folder to the repository root**.
3. Go to **Settings → Pages**.
4. Choose **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save and wait for deployment.

## Notes
- No build step.
- No external libraries.
- All imagery is local SVG artwork.
- Reduced-motion preferences are respected.
- The site contains fictional showcase concepts only; there are no real client or employment claims.
